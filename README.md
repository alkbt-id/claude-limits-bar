# Claude Limits

Утилита для строки меню macOS: показывает 5-часовой и недельный лимиты Claude, время до сброса и историю расхода.

## Что умеет

- **Строка меню**: две мелкие строки — `5ч 42% 11:49` над `7д 61% Пн 20:59` — процент окрашен градиентом зелёный → жёлтый → красный по израсходованности, рядом время сброса. Пока запущены сессии Claude Code, слева столбец: ▶ 2 — сколько работают (зелёным), под ним 🔔 1 — сколько ждут вас (оранжевым).
- **Панель по клику**:
  - лимиты 5 часов и недели: процент, полоска, через сколько и когда сброс;
  - **сессии Claude Code** — все запущенные сейчас (VS Code, терминал, Claude Desktop) с состоянием: работает, работает в фоне (ход окончен, но идут субагенты или фоновые команды), ждёт разрешения или ответа в диалоге, задал вопрос, план ждёт одобрения, ответил и ждёт ввода, остановлена. Рядом — число работающих субагентов и запущенных команд. Сессии сгруппированы: «Ждут вас», «Работают», «Остальные»; отметка снимается кликом по сессии или кнопкой «Всё прочитано», а также сама, если окно сессии и так перед вами (оно впереди, и последнюю минуту вы пользовались клавиатурой или мышью). Окно VS Code узнаётся по заголовку `… — <папка>` — для этого нужен доступ в «Конфиденциальность и безопасность → Универсальный доступ» (кнопка «Разрешить» в панели); вкладка Терминала и iTerm2 — по tty через AppleScript. Сборка подписывается с требованием только на bundle id, поэтому выданные разрешения переживают пересборку. Клик переводит в нужное окно: VS Code — именно то окно, где открыта сессия, и её вкладка (по ссылке расширения Claude Code с номером окна; номер берётся из логов текущего запуска VS Code, `~/Library/Application Support/Code/logs/<время запуска>/window<номер>/renderer.log`, — какое окно запустило процесс `claude`); если окно не нашлось или это `claude` во встроенном терминале — VS Code просто выходит на передний план; Терминал и iTerm2 — вкладка с этой сессией (при первом клике macOS спросит разрешение на управление); остальные терминалы и Claude Desktop — просто выходят на передний план;
  - **расход недельного лимита за 7 дней** — тепловая карта «день × час» по локальным логам `~/.claude/projects`; расход в $ по ценам API пересчитан в долю недельного лимита (справа — итог по дням, в заголовке — за неделю). Пока недельного замера нет, карта в долларах;
  - **топ сессий** за текущее недельное окно с оценкой доли недельного лимита; клик копирует `cd … && claude --resume <id>`.
  - **какой тариф нужен** — пики каждого 5-часового окна и каждой недели за 28 дней пересчитываются на Pro / Max 5x / Max 20x: сколько раз упёрлись бы в лимит и какой тариф самый дешёвый из подходящих; ползунок показывает, где вы среди тарифов. Окна 5 ч у Max ровно ×5 и ×20 от Pro (официально); недельное соотношение Anthropic не публикует — для Max 20x взято 10–20× Pro, поэтому недельная оценка — диапазон. Тариф берётся из токена Claude Code, его можно сменить в панели;
- **Автозапуск** при входе в графическую сессию (LaunchAgent, `LimitLoadToSessionType = Aqua`), переключатель в панели.

## Установка

Нужны macOS 14+ и Swift (Xcode или Command Line Tools).

```bash
./scripts/install.sh     # сборка → ~/Applications/Claude Limits.app, автозапуск, старт
./scripts/uninstall.sh   # удалить приложение и автозапуск
```

## Откуда данные

- Лимиты — `GET https://api.anthropic.com/api/oauth/usage` с OAuth-токеном Claude Code из связки ключей (`Claude Code-credentials`). Опрос раз в 2 минуты, но только если с прошлого опроса в логах Claude Code (`~/.claude/projects`) появилась новая сессия или новое событие; без активности — раз в 30 минут (расход на claude.ai и других машинах в логах не виден) и сразу после сброса окна лимита. Кнопка «Обновить» опрашивает всегда. Токен читается при каждом опросе; если API отверг его (HTTP 401), запросы прекращаются, пока Claude Code не положит в связку ключей новый токен, — тогда приложение опрашивает сразу. Всё это время видны последние данные, а предупреждение — только в панели; запустите Claude Code, он обновит токен.
- История замеров — `~/Library/Application Support/ClaudeLimits/samples.json` (хранится 30 дней); пики окон лимитов для статистики тарифов — `windows.json` там же (хранится год).
- Лог приложения — `~/Library/Logs/ClaudeLimits.log` (запуски, запросы к API, HTTP-ошибки с `Retry-After`, сканы логов; при 1 МБ уходит в `ClaudeLimits.old.log`). Смотреть: `tail -f ~/Library/Logs/ClaudeLimits.log`.
- Запущенные сессии — `~/.claude/sessions/<pid>.json` (их пишет сам Claude Code, файл живёт, пока жив процесс), хвост логов `~/.claude/projects/**/<id>.jsonl`, метаданные субагентов `<id>/subagents/*.meta.json` и дерево процессов (команды — дочерние процессы `claude`, запущенные в своей группе). Опрос раз в 3 секунды. Терминальный Claude Code сам пишет, что ждёт ответа в диалоге; VS Code и Claude Desktop показывают запрос разрешения у себя и не сообщают о нём, поэтому для них «ждёт разрешения?» — догадка: вызов инструмента висит дольше 10 секунд без записей в логе, без команд и субагентов. Отладка: `ClaudeLimits --sessions [--watch]` печатает то же, что покажет панель.
- Топ сессий и тепловая карта «Claude Code» — логи `~/.claude/projects/**/*.jsonl`. Расход считается в долларах по ценам API и пересчитывается в долю недельного лимита пропорционально — это оценка, а не точное значение. Чаты на claude.ai в логах не видны.
