# Claude Limits

Утилита для строки меню macOS: показывает 5-часовой и недельный лимиты Claude, время до сброса и историю расхода.

![menu bar](docs/menubar-light.png)

<img src="docs/panel-light.png" width="470" alt="panel">

## Что умеет

- **Строка меню**: две мелкие строки — `5ч 42% 2ч13м` над `7д 61% 2д19ч` — процент окрашен градиентом зелёный → жёлтый → красный по израсходованности, рядом время до сброса.
- **Панель по клику**:
  - карточки лимитов со временем сброса;
  - **какой тариф нужен** — пики каждого 5-часового окна и каждой недели за 28 дней пересчитываются на Pro / Max 5x / Max 20x: сколько раз упёрлись бы в лимит и какой тариф самый дешёвый из подходящих; ползунок показывает, где вы среди тарифов. Окна 5 ч у Max ровно ×5 и ×20 от Pro (официально); недельное соотношение Anthropic не публикует — для Max 20x взято 10–20× Pro, поэтому недельная оценка — диапазон. Тариф берётся из токена Claude Code, его можно сменить в панели;
  - **расход за 7 дней**, две вкладки:
    - **Claude Code** — тепловая карта «день × час» по локальным логам `~/.claude/projects`, сразу за всю неделю;
    - **Лимиты** — график 5-часового и недельного лимита по замерам приложения;
  - **топ сессий** за текущее недельное окно с оценкой доли недельного лимита; клик копирует `cd … && claude --resume <id>`.
- **Автозапуск** при входе в графическую сессию (LaunchAgent, `LimitLoadToSessionType = Aqua`), переключатель в панели.

## Установка

Нужны macOS 14+ и Swift (Xcode или Command Line Tools).

```bash
./scripts/install.sh     # сборка → ~/Applications/Claude Limits.app, автозапуск, старт
./scripts/uninstall.sh   # удалить приложение и автозапуск
```

## Откуда данные

- Лимиты — `GET https://api.anthropic.com/api/oauth/usage` с OAuth-токеном Claude Code из связки ключей (`Claude Code-credentials`). Опрос раз в 2 минуты, но только если с прошлого опроса в логах Claude Code (`~/.claude/projects`) появилась новая сессия или новое событие; без активности — раз в 30 минут (расход на claude.ai и других машинах в логах не виден) и сразу после сброса окна лимита. Кнопка «Обновить» опрашивает всегда. Токен читается при каждом опросе; если он истёк, приложение показывает последние данные, а предупреждение — только в панели; запустите Claude Code, он обновит токен.
- История замеров — `~/Library/Application Support/ClaudeLimits/samples.json` (хранится 30 дней); пики окон лимитов для статистики тарифов — `windows.json` там же (хранится год).
- Лог приложения — `~/Library/Logs/ClaudeLimits.log` (запуски, запросы к API, HTTP-ошибки с `Retry-After`, сканы логов; при 1 МБ уходит в `ClaudeLimits.old.log`). Смотреть: `tail -f ~/Library/Logs/ClaudeLimits.log`.
- Топ сессий и тепловая карта «Claude Code» — логи `~/.claude/projects/**/*.jsonl`. Расход считается в долларах по ценам API и пересчитывается в долю недельного лимита пропорционально — это оценка, а не точное значение. Чаты на claude.ai в логах не видны.
