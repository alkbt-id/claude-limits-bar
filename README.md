# Claude Limits

Утилита для строки меню macOS: показывает 5-часовой и недельный лимиты Claude, время до сброса и историю расхода.

![menu bar](docs/menubar-light.png)

<img src="docs/panel-light.png" width="470" alt="panel">

## Что умеет

- **Строка меню**: две мелкие строки — `5ч 42% 2ч13м` над `7д 61% 2д19ч` — процент окрашен градиентом зелёный → жёлтый → красный по израсходованности, рядом время до сброса.
- **Панель по клику**:
  - карточки лимитов со временем сброса;
  - график лимитов за 7 дней (по замерам приложения);
  - тепловая карта «день × час» — когда лимит расходовался больше всего. Три источника:
    - **Claude Code** — по локальным логам `~/.claude/projects`, сразу за всю неделю;
    - **Лимит 5ч / Лимит недели** — прирост процента лимита за час по замерам приложения;
  - **топ сессий** за текущее недельное окно с оценкой доли недельного лимита; клик копирует `cd … && claude --resume <id>`.
- **Автозапуск** при входе в графическую сессию (LaunchAgent, `LimitLoadToSessionType = Aqua`), переключатель в панели.

## Установка

Нужны macOS 14+ и Swift (Xcode или Command Line Tools).

```bash
./scripts/install.sh     # сборка → ~/Applications/Claude Limits.app, автозапуск, старт
./scripts/uninstall.sh   # удалить приложение и автозапуск
```

## Откуда данные

- Лимиты — `GET https://api.anthropic.com/api/oauth/usage` с OAuth-токеном Claude Code из связки ключей (`Claude Code-credentials`). Токен читается при каждом опросе (раз в 2 минуты); если он истёк, приложение показывает последние данные, а предупреждение — только в панели; запустите Claude Code, он обновит токен.
- История замеров — `~/Library/Application Support/ClaudeLimits/samples.json` (хранится 30 дней).
- Топ сессий и тепловая карта «Claude Code» — логи `~/.claude/projects/**/*.jsonl`. Расход считается в долларах по ценам API и пересчитывается в долю недельного лимита пропорционально — это оценка, а не точное значение. Чаты на claude.ai в логах не видны.
